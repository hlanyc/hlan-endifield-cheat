## Features

**Player:**
- Movement speed
-  skill and ultimate cooldown control
-  god mode
-  damage multiplier
-  unlimited stamina
-  jump adjustment
-  free flight.

**World:**
- Entity markers
- automatic pickup
- gathering
- chest interaction
- extended interaction range
- enemy attraction
- instant stagger with adjustable range and interval
- auto puzzle
- kill aura
- Skip supported dialogue(cutscenes, and videos, adjust playback speed, and advance dialogue automatically)

**Travel:**
- Zipline speed adjustment
- coordinate teleportation
- saved locations
- automatic routes
- quest or chest teleport shortcuts.

**Extras:**
- Character anti-fade
- FPS display

**Settings:**
- English and Chinese interface
- saved configurations
- customizable hotkeys.
